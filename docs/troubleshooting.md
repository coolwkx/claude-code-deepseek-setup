# 常见问题排查

按“软件 → 启动入口 → 密钥 → 模型 → 网络”的顺序检查，不要先反复充值。

| 现象 | 先检查什么 | 处理方式 |
| --- | --- | --- |
| 找不到 `code.cmd` | VS Code 是否加入 PATH | 安装时启用 PATH，重开 PowerShell，再运行 `Get-Command code.cmd` |
| Claude Code installation is not ready | 默认安装路径 | 检查用户目录 `.local/bin/claude.exe`；按官方安装说明安装，或修改启动脚本路径 |
| 扩展安装失败 | 网络、版本是否可下载 | 查看错误，验证官方扩展源是否可达；不要继续执行汉化 |
| 中文语言包不兼容 | VS Code 和语言包版本 | 用与编辑器匹配的语言包；固定模板适用于记录的 1.104 版本 |
| 菜单中文、聊天仍英文 | 语言包与扩展面板不同 | 可应用固定版本汉化补丁；部分英文仍可能保留 |
| 双击启动入口没有窗口 | 隐藏入口不显示错误 | 在 PowerShell 运行下面的 `Start-Client.ps1` 查看错误 |
| 仍提示登录 Claude | 是否从专用入口启动 | 关闭专用窗口并用桌面入口打开，检查专用设置和密钥 |
| 401 或认证失败 | DeepSeek 密钥是否有效 | 在本机重新保存自己的 API 密钥；不要贴到问题反馈中 |
| 余额不足 | API 账户可用额度 | 到官方平台核对账户、额度和充值状态 |
| 模型不存在 | 启动脚本的模型名称 | 对照 DeepSeek 当前官方接入指南调整模型环境变量 |
| Token 为 0 或暂时不变 | 项目、记录是否写入 | 完成一次小请求，等记录落盘；确认打开的是对应项目 |
| 最近会话不是正在看的会话 | 统计按写入时间排序 | 属于已说明的限制；监控不能可靠读取当前所选聊天 |
| 余额“未更新” | 网络、密钥、代理 | 点击立即查询，检查官方平台；旧数值不能当成当前余额 |
| 状态栏没有监控 | 专用扩展目录 | 运行 `Install-Monitor.ps1` 后重载专用窗口 |
| 新电脑解密失败 | Windows 本机加密绑定 | 在新电脑重新运行 `Save-ApiKey.ps1` |
| Git 下载无权限 | 仓库可见性 | 私有仓库需要获得 GitHub 授权；作者公开前无法匿名下载 |

## 查看启动错误

```powershell
Set-Location D:\ClaudeCode-DeepSeek
powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-Client.ps1
```

窗口正常打开后这条命令可能保持运行，这是等待客户端退出的正常行为。

## 代理问题

启动器和余额查询会读取 Windows Internet Settings 中启用的、形如 `127.0.0.1:端口` 的代理。复杂的协议分组、PAC、公司网关或其他格式不由脚本自动处理。若电脑曾依赖本地代理，关闭它可能导致连接失败；检查真实配置，不要随便套用别人电脑的端口。

安装脚本访问的软件源与运行时 DeepSeek 接口是不同地址：一个能联网不代表另一个可达。官方平台网页能打开也不代表 API 请求已成功。

## 反馈前的最少信息

提供 Windows、VS Code、Claude Code 的版本；说明执行到哪一步，附脱敏后的错误文字即可。不要提交 `config`、客户端日志目录、完整聊天记录、API 密钥、Authorization 请求头或个人身份资料。
