# 日常使用、费用与维护

## 怎么给助手任务

从桌面专用入口打开项目，先说明目标、范围和验收条件。例如：

> 请用中文解释这个项目的结构和启动方法，暂时不要修改文件。

> 请修复登录按钮点击后没有反应的问题。先定位原因，再修改相关文件，最后说明怎么验证。

> 请添加一个待办事项页面，支持新增、勾选完成和删除。先给出实现计划，完成后说明修改了哪些文件。

任务越具体，越容易审阅结果。尽量一次完成一个目标；修复新问题可以开新会话。涉及安装依赖、执行命令或修改文件时，阅读客户端的确认提示。初学者先使用手动确认模式，查看修改差异后再决定是否保留。

## 怎么看 Token

状态栏 `Token 本项目 ↑… ↓…` 分别表示累计输入和输出；输入包含记录中的缓存读取、缓存写入。点击后可看普通输入、缓存、输出、项目累计、各会话累计及最近有记录的会话。

这些数值统计的是本机当前项目顶层会话记录，不是整个账户、当前上下文占用或所有子代理用量。请求记录写入后才更新。最近有记录的会话不一定是界面当前选中的会话。项目总数跨会话去重，分支会话各自包含的历史不能直接相加当成项目总数。

监控每 5 秒检查文件是否变化，未变化时复用数据；这项工作不调用模型。

## 怎么看余额与账单

点击余额状态栏查看最近查询时间、充值余额、赠送余额和本次启动以来的余额变化。活跃时每 30 秒查询，失焦或 2 分钟未观察到编辑/记录活动后每 5 分钟查询；点击可立即查询。

“未更新”表示查询失败，显示的是之前成功取得的数值。余额下降可能来自其他工具或赠送额度变化，并非当前项目的精确账单。逐笔消费、充值和实际价格请到 [DeepSeek 官方平台](https://platform.deepseek.com/usage) 核对。

在设置搜索 `deepseekMonitor`：

| 设置 | 默认值 | 含义 |
| --- | --- | --- |
| `lowBalanceCNY` | 10 | 人民币余额低于此值时提醒 |
| `lowBalanceUSD` | 2 | 美元余额低于此值时提醒 |
| `dropWarningCNY` | 5 | 10 分钟内人民币余额下降到此金额时提醒 |
| `dropWarningUSD` | 1 | 10 分钟内美元余额下降到此金额时提醒 |

数值设为 0 可关闭对应提醒。提醒只通知，不会阻止模型继续消费，也不是自动充值功能。低余额提醒去重，恢复至阈值的 110% 后重新启用；下降提醒冷却 10 分钟，余额上升后重新观察。

## 怎样减少不必要的用量

先让助手定位相关文件，再执行具体修改；避免不断要求扫描整个大型仓库。不要把无关的大日志、生成文件和依赖目录反复放入问题中。长会话积累很多历史时，结束一个任务后开新会话。选择模型与推理强度前参考服务商当前支持与价格，而不是仅按名字猜费用。

输入 Token 会包含每次请求携带的上下文，因此累计输入可能明显大于你手工输入的文字。缓存 Token 是否按不同价格计费以官方为准，界面 Token 总数不能直接乘一个单价当作账单。

## 更新、恢复与迁移

已有 Git 仓库更新前关闭专用客户端，并保留自己修改的脚本：

```powershell
Set-Location D:\ClaudeCode-DeepSeek
git status
git pull --ff-only
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Monitor.ps1
```

若 `git status` 有本地修改，先审阅并保存，不要用强制覆盖解决。下载 ZIP 的读者只替换需要的教程和源文件，保留运行目录与加密密钥。

`Prepare-Client.ps1` 保留已存在的设置，因此更新模板不自动更新你已用的设置。扩展升级前先恢复原界面；升级后不要用旧版汉化备份覆盖新版扩展。

恢复汉化（先关闭客户端）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Apply-Chinese.ps1 -Restore
```

API 密钥失效或希望轮换时，重新执行 `Save-ApiKey.ps1`，再关闭并重启客户端。迁移电脑时重新保存密钥，加密文件不能跨电脑复用。API 密钥应在官方平台撤销旧密钥。

扩展自动更新只在专用配置中关闭，Claude Code 独立程序的更新机制另行管理。定期检查官方更新说明并重新验证模型连接、中文界面和监控。
